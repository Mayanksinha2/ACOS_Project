# ADR-003

## Title

Adoption of ACNP v2 for Inter-Agent Communication

## Status

Accepted

## Context

Autonomous commerce agents require a standardized, explainable, and auditable communication protocol.

## Decision

All communication between agents and the ACOS Kernel shall use ACNP v2 messages carrying Commerce Decision Objects.

## Consequences

Positive:
- Standardized communication
- Easy auditing
- Replay capability
- Supports future distributed deployment

Negative:
- Slight increase in protocol complexity
