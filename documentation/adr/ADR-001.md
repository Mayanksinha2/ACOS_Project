# ADR-001

## Title

Adoption of Commerce Decision Object (CDO)

## Status

Accepted

## Context

Agents require a standardized representation for exchanging business decisions.

## Decision

All inter-agent communication shall use the Commerce Decision Object (CDO).

## Consequences

Positive:
- Standard communication
- Explainability
- Easier negotiation
- Better traceability

Negative:
- Slightly increased implementation complexity
