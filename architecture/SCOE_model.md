# Self Improving Commerce Optimization Engine (SCOE)


The system learns from previous decisions.


Learning Record:


L = {


Decision,

Context,

Expected Outcome,

Actual Outcome,

Reward

}



The reward updates future decision priorities.


Example:


Decision:

10% price increase


Expected:

+10% profit


Actual:

+18% profit


Reward:

Positive


Future confidence increases.
